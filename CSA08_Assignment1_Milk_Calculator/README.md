## Design assumptions
The original brief explicitly gives a fat range of 2.0%–7.0%, base fat 3.5%, base SNF 8.5%, and adjustment increments. It does not state an SNF acceptance range, so the sample validator uses 6.0%–10.0% as a clearly labelled configurable assumption. Change it to the co-operative's official limit if supplied. The seasonal requirement changes the base rate and fat step for April–June; the original SNF step is retained because no seasonal SNF change is specified. The bonus is applied to all litres supplied in the ten-day period once total litres exceed 500.
